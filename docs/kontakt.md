# Kontakt

## Erstgespräch { #erstgespraech }

Im Erstgespräch klären wir euren Anlass und schlagen ein passendes Format vor. 30 Minuten, kostenlos. Schreibt uns kurz, worum es geht, wir melden uns mit Terminvorschlägen.

[Erstgespräch per E-Mail anfragen](mailto:info@cogneon.de?subject=Erstgespr%C3%A4ch){ .cg-button }

Für alles andere erreicht ihr uns unter [info@cogneon.de](mailto:info@cogneon.de?subject=Kontakt%20%C3%BCber%20cogneon.de) oder telefonisch unter +49 911 39570830.
