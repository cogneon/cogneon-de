# lernOS Convention 2023 „Crafting Learning Environments“

Die **lernOS Convention 2023** (#loscon23) findet vom 11.-12. Juli 2023 unter dem **Motto „Crafting Learning Environments“** statt. Die loscon23 ist eine hybride Veranstaltung zu [lernOS](https://lernos.org), Ihr könnt auf der Kaiserburg in Nürnberg oder Online teilnehmen.

![](/wp-content/uploads/2023/04/loscon23-key-visual-1030x579.png)

Alle Infos zur Veranstaltung folgen unter [cogneon.de/loscon23](/loscon23). Ihr könnt zusätzlich [@lernos](https://colearn.social/@lernos) oder dem **Hashtag [#loscon23](/tag/loscon23/)** auf Mastodon oder [auf Linkedin](https://www.linkedin.com/search/results/content/?keywords=loscon23&sid=)Ao) folgen. Den Frühbucher-Preis gibt es bis zum 31.03.2023.
