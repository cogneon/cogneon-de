# 3. Audio-only Barcamp (#audiobc23)

Das **3. Audio-only BarCamp** (#audiobc23) **am 20.09.2023** (10-17 Uhr) ist ein [BarCamp](https://web.archive.org/web/20220223175106/https://de.wikipedia.org/wiki/Barcamp) zu **Social Audio und Podcasting in Organisationen**. Das audiobc23 findet [wie letztes Jahr](https://wiki.cogneon.de/audiobc22) **wieder online** statt, dieses Mal mit [Discord](https://de.wikipedia.org/wiki/Discord) als Plattform.
