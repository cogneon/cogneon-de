# #lernOS Lighning Talk auf dem 36C3

Auf dem [36. Chaos Communication Congress](https://events.ccc.de/congress/2019/wiki/index.php/Main_Page) (#36c3) habe ich an Tag 4 (30.12.2019) einen [Lightning Talk](https://de.wikipedia.org/wiki/Lightning_Talk) zu [lernOS](/lernos) gehalten. Gemäß des Lightning Talk Formats habe ich versucht, die große lernOS Idee für Individuen in 5 Minuten vorzustellen. Seht selbst, ob mir das gelungen ist (Kritik gerne in die Kommentare):

<!-- more -->

[YouTube: lernOS – Hacking How We Learn – Lifelong](https://www.youtube.com/watch?v=7atMXYyzkBc){ .embed }

Lightning Talks gab es an 2, 3 und 4 des Kongresses mit jeweils 2,5 Stunden Talks (der erste ist immer eine Einführung in das Format). Das Programm gibt euch einen Überblick über die Themen, auf media.ccc.de. findet ihr die Aufzeichnungen von [Tag 2](https://media.ccc.de/v/36c3-10524-lightning_talks_day_2), [Tag 3](https://media.ccc.de/v/36c3-10525-lightning_talks_day_3) und [Tag 4](https://media.ccc.de/v/36c3-10526-lightning_talks_day_4).
