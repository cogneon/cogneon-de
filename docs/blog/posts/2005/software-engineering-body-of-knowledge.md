# Software Engineering Body of Knowledge

Die IEEE Computer Society ([http://computer.org](https://www.computer.org/web/guest)) stellt mit dem SWEBOK (Software Engineering Body of Knowledge, [http://www.swebok.org/ironman/pdf/SWEBOK_Guide_2004.pdf](https://web.archive.org/web/20070916220707/http://www.swebok.org/ironman/pdf/SWEBOK_Guide_2004.pdf)) geballtes Software-Wissen zur Verfügung. Die behandelten Wissensgebiete sind:

<!-- more -->

- Software requirements
- Software design
- Software construction
- Software testing
- Software maintenance
- Software configuration management
- Software engineering management
- Software engineering process
- Software engineering tools and methods
- Software quality

Interessant ist auch das Reifegradmodell, das eine Entwicklung innerhalb von ca. 5 Jahren in 3 Phasen ([http://www.swebok.org/3phases.html](https://web.archive.org/web/20070916220707/http://www.swebok.org/3phases.html)) definiert:

1. Straw Man
2. Stone Man
3. Iron Man
