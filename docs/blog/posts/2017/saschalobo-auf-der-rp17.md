# @saschalobo auf der #rp17

Der Vortrag von [@saschalobo](https://twitter.com/saschalobo) auf der re:publica (#rp17) dieses Jahr trug den Titel **„Vom Reden im Netz – Serviervorschlag zur Stärkung der liberalen Demokratie mithilfe der sozialen Medien“**. Der Vortrag steht mittlerweile [auf YouTube](https://youtu.be/xwVtbDd6_dY) zum Nachsehen bereit.

<!-- more -->

[YouTube: re:publica 2017 – Sascha Lobo: Vom Reden im Netz.](https://youtube.com/watch?v=xwVtbDd6_dY){ .embed }

Darin eine schöne Aufzählung von Effekten der kognitiven Verzerrungen in sozialen Medien:

- [Mitläufer-Effekt](https://de.wikipedia.org/wiki/Mitläufereffekt)
- [Bestätigungsfehler](https://de.wikipedia.org/wiki/Bestätigungsfehler)
- [Attributionsfehler](https://de.wikipedia.org/wiki/Attributionsfehler)
- [Ankereffekt](https://de.wikipedia.org/wiki/Ankereffekt)
- [Framing-Effekt](https://de.wikipedia.org/wiki/Framing-Effekt)
- [Wahrheitseffekt](https://de.wikipedia.org/wiki/Wahrheitseffekt_und_Wahrheitsurteile)
- [Blinder Fleck](https://de.wikipedia.org/wiki/Blinder_Fleck_(Psychologie))
- Untergangsglaube
- [Maslows Hammer](https://de.wikipedia.org/wiki/Law_of_the_Instrument)
- [Illusorische Korrelation](https://de.wikipedia.org/wiki/Illusorische_Korrelation)
- [Semmelweis-Reflex](https://de.wikipedia.org/wiki/Semmelweis-Reflex)
- [Just-World-Hypothese](https://de.wikipedia.org/wiki/Gerechte-Welt-Glaube)
- [Naiver Realismus](https://de.wikipedia.org/wiki/Naiver_Realismus)
- „Virtualität“
