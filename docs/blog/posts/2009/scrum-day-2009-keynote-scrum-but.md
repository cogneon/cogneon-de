# Scrum Day 2009: Keynote: „Scrum, But…“

*Dieser Blog-Beitrag wurde von der ehemaligen Nutzerin kerstin.buecher verfasst.*

<!-- more -->

**Zum Vortrag**

- Referent: Ken Schwaber (<http://www.controlchaos.com/>)
- Scrum values: transparency, empiricism, self-organization, integrity, delivery
- complexity is today is too high to be understood. One month is the time interval that a human being can be overseen in project context. 35% of a project changes.
- Lean thinking, Just-in-time
- „We don’t have time to…“
- Scrum is a framework including roles, rules, artifacts and timeboxes. It’s not a work instruction.
