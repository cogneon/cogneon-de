# How to use the lernOS Canvas as Tool in Working Out Loud Circles (#WOL)

Over the last years I developped **a Canvas** that can be used **as tool in Working Out Loud Circles**. I described that Canvas [in this blog post](/2018/05/24/wol-a-tool-for-wol-circle-alumni-and-knowledge-workers/). In the blog and also in a post in the WOL facebook group I offered to run a web conference to explain the canvas and how to use it in the context of WOL. Some 60 people liked the idea and responded to the doodle to find time and date for the web conference.

<!-- more -->

**The result of the doodle poll:** we run a web conference at Monday 2018/7/9 from 4-5pm CEST (find your time [at time.is](https://time.is/de/CEST)). We will use zoom.us as a video conferencing service (link for participation: [zoom.us/j/497571515](https://zoom.us/j/497571515)). If you plan to take part please [put your name in that doodle](https://doodle.com/poll/fc2dvaa5q4kx8hib) so I have an idea how many people will join.

[Zoom Web Conference (2018/7/9, 4-5pm CEST)](https://zoom.us/j/497571515)
